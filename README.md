# 🌐 Ayush Raj — Portfolio Website

A personal portfolio website showcasing my software engineering projects, skills, experience, and contact information. Built with a focus on clean design, performance, and responsive user experience.

🔗 **Live Demo:** [https://a-rajyush.github.io/ayush-portfolio-site](https://a-rajyush.github.io/ayush-portfolio-site) *(or your deployed custom domain / Vercel link)*

---

## ✨ Features

- **Responsive Design:** Optimized for seamless viewing across mobile, tablet, and desktop screens.
- **Projects Showcase:** Interactive cards highlighting personal projects with live demo links, repository links, and tech tags.
- **Skills & Tech Stack:** Categorized breakdown of programming languages, frameworks, libraries, and developer tools.
- **About & Experience:** Brief professional background, timeline of education, and work experience.
- **Contact Form / Links:** Easy ways to get in touch via email, LinkedIn, and social profiles.
- **Fast Performance:** Clean and lightweight architecture for fast page loads and smooth scrolling.

---

## 🛠️ Built With

- **Frontend:** HTML5, CSS3 / Tailwind CSS, JavaScript / TypeScript *(or React / Next.js)*
- **Icons & Assets:** Lucide Icons / Font Awesome
- **Deployment:** GitHub Pages / Vercel / Netlify
